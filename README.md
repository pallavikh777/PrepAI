# PrepAI

## AI-Powered Interview Preparation Platform

PrepAI is a full-stack AI-powered web application that helps students and job seekers prepare for interviews through personalized mock interviews, resume analysis, coding assessments, and AI-generated feedback.

## Tech Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- PostgreSQL

### AI
- Google Gemini API
